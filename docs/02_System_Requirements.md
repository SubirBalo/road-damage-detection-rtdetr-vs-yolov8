# 2. System Requirements

This document defines the functional and non-functional requirements for the AI-Based Road Damage Detection System. These requirements provide a structured foundation for system design, implementation, testing, deployment, and future extensions.

The objective is to develop a reproducible embedded AI platform capable of detecting and classifying road surface damage using deep learning models deployed on NVIDIA Jetson Nano with a Luxonis OAK-D smart camera.

## System Scope

The system shall perform real-time road damage detection using an embedded AI platform.

The complete system includes:

- Image acquisition
- AI inference
- Damage classification
- Visualization
- Performance evaluation
- Embedded deployment
